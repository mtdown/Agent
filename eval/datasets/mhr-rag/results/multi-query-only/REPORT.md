## 6. 同题 A/B：只能做 147 题交集（重要限制）

任务 2.3 要求"固定 600 题检索 **A/B**"。但负责人明确指示**不做固定 600 题基线（任务 1.4 未执行）**，
因此本轮只有 ON 臂。为不把"不同题集相减"当改进证据，这里只用**磁盘上已有的同题数据**做交集对比：

| | 本轮（多查询 ON） | 历史 run `mhr-20260916-233042`（多查询 OFF） |
|---|---|---|
| 题目集 | `mhr-eval-600-fixed.jsonl` 600 题 | `golden.mhr.jsonl` 前 600 题 |
| fetchK | 50 | 10 |
| 多查询代码 | 有（文件创建于 2026-09-17 13:05 / 14:24） | **不可能有**（文件当时还不存在） |
| 二者题目交集 | **147 题**（可答 128 / 拒答 19） | 同 |

**交集上重算（n=128，同题同 K，唯一可比口径）**

| metric | 多查询 ON (fetch50) | OFF (fetch10) | delta |
|---|---|---|---|
| recall@6 | 0.7448 | 0.7422 | **+0.0026** |
| recall@10 | 0.8327 | 0.8255 | +0.0072 |
| docRecall@6 | 0.7995 | 0.8001 | −0.0006 |
| docRecall@10 | 0.8880 | 0.8835 | +0.0045 |
| hitRate@6 | 0.9844 | 0.9922 | −0.0078 |
| mrr | 0.8640 | 0.8666 | −0.0026 |

- **147 题里 top-6 完全一致 127 题，变化 20 题**（说明多查询确实改变了候选集，不是"没生效"）。
- `recall@6` 差 **+0.26pt**，未超过本项目"<0.2pt 不算证据"的判据边缘，且 `mrr` 反而 −0.26pt、
  `hitRate@6` −0.78pt。**在可观测范围内，多查询没有带来可测增益。**

**这个对比不构成定论**，原因有二：
1. n=128 太小，且是"固定 600 ∩ 历史前 600"的偶然子集，不是分层代表样本；
2. 两次 run 相隔半天，存在已知的检索非确定性（同数据重跑极差 0.13pt 量级）。
   ⇒ 要拿到可信 A/B，唯一办法是**对同一份固定 600 题跑一次多查询 OFF**（即任务 1.4），
   该臂不含 LLM 调用，预计 **5–10 分钟**即可跑完。

## 7. 可比性声明（不得越界引用）

1. 本数据集是**纯向量 + BM25 + 重排**链路，`文号层对英文恒不生效` —— 与自有 216 篇中文集的
   「向量 + 文号钉位」混合链路**不可横比绝对值**。
2. 本轮数字是**绝对值**，不是"多查询 +X pt"。任何改进声明必须等第 6 节所述 OFF 臂补齐。
3. 71 道 `null_query` 的**拒答行为未被测量**：现有 runner 对无 gold 题目直接计拒答、不调检索接口。
   因此 MHR 上的"拒答正确率"仍为空白，需答案层 runner（见第 8 节）。
