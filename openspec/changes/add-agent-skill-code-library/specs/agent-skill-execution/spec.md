# Spec Delta

## Purpose

在保持现有 Agent 聊天可用的同时，为用户的 Skill 和在线代码提供有界执行能力，并让文件、知识库、历史会话及库条目操作遵守当前用户权限。

## ADDED Requirements

### Requirement: 用户隔离的执行空间
系统 SHALL 为每个用户隔离代码执行目录；代码可在本人目录内读写文件，不得通过路径遍历或共享进程访问其他用户目录或宿主机任意路径。

#### Scenario: 本人文件操作
- **WHEN** 用户的代码在本人执行目录中创建、读取或修改文件
- **THEN** 操作成功且结果仅在本人授权范围可见

#### Scenario: 跨用户路径
- **WHEN** 代码尝试使用绝对路径或路径遍历访问其他用户的执行目录
- **THEN** 执行器拒绝访问且不泄露目标内容

### Requirement: 受权限约束的资源操作
Skill 和代码 SHALL 能按当前用户权限访问知识库空间、本人历史会话、本人或获共享的 Skill 与代码项；读写、删除及发布操作 SHALL 各自复核资源的现有授权规则，不因 Skill 共享而扩大资源权限。

#### Scenario: 读取授权知识库
- **WHEN** Skill 为当前用户读取其可见空间内的文档
- **THEN** 返回该用户当前有权读取的内容

#### Scenario: 执行时失权
- **WHEN** 用户启用 Skill 后失去某空间或代码项的使用权限
- **THEN** 再次执行时该资源操作被拒绝，不能使用旧授权缓存继续读取

#### Scenario: 未授权修改
- **WHEN** Skill 尝试修改当前用户只有读取权限的知识库或他人的库条目
- **THEN** 修改被拒绝且数据不变

### Requirement: 有界运行和故障定位
Python/Java 代码执行 SHALL 设定超时、并发及资源上限，并记录调用的 Skill 版本、代码版本、步骤、耗时及结果；失败时 SHALL 停止受影响步骤并给出可定位的原因，不自行切换代码版本。

#### Scenario: 运行超时
- **WHEN** 某代码步骤超过限制
- **THEN** 该执行被终止，聊天服务仍可响应其他请求，用户收到步骤及超时原因

#### Scenario: 代码版本不可用
- **WHEN** Skill 固定引用的代码版本不存在、不可用或当前用户无权使用
- **THEN** 系统拒绝该步骤并说明原因，不改用最新版本

#### Scenario: 正常聊天兼容
- **WHEN** 用户提问未使用 Skill 或代码执行不可用
- **THEN** 现有 Agent 对话与授权 RAG 引用功能仍可使用
