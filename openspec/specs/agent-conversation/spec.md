# agent-conversation Specification

## Purpose

让登录用户在 AI 助手中保存、重新打开并继续自己的 Agent 对话，同时保证会话内容只对本人可见，且多轮回答使用有界的历史上下文。

## Requirements

### Requirement: 用户私有会话
系统 SHALL 持久保存 Agent 会话和按顺序排列的消息；所有读取、续聊与删除操作 SHALL 以当前登录用户为归属边界，管理员没有跨用户查看通道。

#### Scenario: 重新打开历史会话
- **WHEN** 用户刷新页面并打开自己的会话
- **THEN** 系统按原顺序返回问题、回答、引用和生成指标

#### Scenario: 历史列表与首问标题

- **WHEN** 用户在 Agent 模式发送某会话的第一个问题并重新加载页面
- **THEN** 左侧历史列表显示该问题的前 80 个字符作为标题；默认标题和已有乱码占位标题均不会覆盖首问标题

#### Scenario: 重命名和删除

- **WHEN** 用户在左侧历史条目的三点菜单中重命名或删除自己的会话
- **THEN** 列表即时更新且刷新后仍保持结果；非所有者（包括管理员）无法重命名或删除该会话

#### Scenario: 长时间流式回答

- **WHEN** 模型生成超过 30 秒但仍在 Agent 规定时限内
- **THEN** Cloud 和 Agent 的异步请求保持打开，正常返回完成事件并保存回答

#### Scenario: 不得访问他人的会话
- **WHEN** 登录用户（包括管理员）请求其他用户的会话 ID
- **THEN** 系统拒绝读取、续聊或删除，且不泄露对话内容

### Requirement: 多轮上下文
系统 SHALL 将同一会话中最近的已完成问答作为后续 Agent 请求的上下文，不跨会话混用，也不把对话自动加入知识库。

#### Scenario: 追问上一个问题
- **WHEN** 用户在已完成上一轮的会话中追问上一个问题
- **THEN** Agent 输入包含该会话的最近问答，能够引用前一轮用户问题

#### Scenario: 新建会话
- **WHEN** 用户开始新会话
- **THEN** Agent 输入不含旧会话的消息

#### Scenario: 生成中断
- **WHEN** 生成失败或流连接中断
- **THEN** 已接收的用户问题仍可见，但未完成的回答不会作为后续轮次的已完成上下文

### Requirement: 会话流式输出
Agent SHALL 保持现有增量输出和耗时、token 指标，并将成功回答及其引用与指标归入对应会话。

#### Scenario: 完成一轮流式回答
- **WHEN** 用户在会话中发送问题且生成成功
- **THEN** 回答增量呈现，完成后刷新页面仍能看到该轮回答及指标
