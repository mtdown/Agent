验收与观察

固定验收要求文件分段、有限候选扫描和版本变更拒绝。测试通过；每次计算摘要另有整文件流式读取。51 次 × 50 MiB = 2550 MiB（约 2.49 GiB）逻辑摘要读取，非物理磁盘实测。负责人暂缓完整资源优化，该成本不计固定项 FAIL。
