## 一、前端改造（面试演示的基础）

### 移动端适配

| 文件 | 改动 |
|---|---|
| `cloud_front/src/styles/mobile.css` | **新增**。768px 断点：表格横向滚动、抽屉/弹窗窄屏铺满、分页换行、触摸目标 34/36px、`.ant-space`/`.ant-form-inline` 允许换行。只处理「溢出 + 可点性」，刻意不动布局 |
| `cloud_front/src/main.ts` | 引入 `mobile.css` |
| `HomePage.vue` | 搜索框 `400px` → 窄屏 100%，搜索栏改上下堆叠 |
| `PictureDetailPage.vue` | 预览图写死 `500×500` → 窄屏 `width:100%; height:auto; max-height:45vh` |

### 前后端同源代理（关键）

| 文件 | 改动 |
|---|---|
| `cloud_front/vite.config.ts` | `server.proxy` 把 `/api` 转发到 `127.0.0.1:8123`（后端 context-path 就是 `/api`，**不 rewrite**）；`allowedHosts: true`；`port: 3000`；新增 `preview` 块（配置同 server） |
| `cloud_front/src/request.ts` | `DEV_BASE_URL` → `''`（同源）；`timeout` 10s → **60s** |

为什么这么做：

- 前后端共用 3000 一个端口 → 穿透只要转一个端口；
- 穿透域名是 https 时不会出现「https 页面请求 http 接口」被浏览器拦；
- Vite 6 默认只放行 localhost / 纯 IP 的 Host，**不配 `allowedHosts` 穿透域名会被拦**；
- 本机首次 RAG 检索约 20s，10s 超时会误判。

## 二、脚本改造

| 文件 | 改动 |
|---|---|
| `start-dev.ps1` | 新增 `-Public`（兼容保留）、`-NoTunnel`、`-Tunnel`、`-Preview`、`-NoPause`；默认起公网隧道；末尾等待回车 |

### 现在怎么用

```powershell
# 公网演示（推荐）：打包产物 + 自动穿透 + 末尾暂停
powershell -ExecutionPolicy Bypass -File .\start-dev.ps1 -Preview

# 只走局域网，不暴露公网
powershell -ExecutionPolicy Bypass -File .\start-dev.ps1 -NoTunnel

# 日常开发切最新 main 代码：默认不暴露公网
powershell -ExecutionPolicy Bypass -File .\start-main-dev.ps1
powershell -ExecutionPolicy Bypass -File .\start-main-dev.ps1 -Public -Stay   # 演示用
```

## 三、过程中修掉的真实问题

1. **脚本原本跑不起来**：`"$lanIp:$frontPort"` 被 PowerShell 当成作用域限定变量，整份脚本 ParserError。改成 `$($lanIp):$($frontPort)`。
2. **端口不一致**：`vite.config.ts` 写成 5173，而 `start-dev.ps1`/`stop-dev.ps1` 一直是 3000 → 统一回 3000。
3. **自己引入的编码坑**：给 `start-dev.ps1` 的 param 加中文注释后脚本解析失败。该文件必须**纯 ASCII**（PS 5.1 对无 BOM 文件按系统 ANSI 解码）。
4. **局域网 IP 取到虚拟网卡**：按 InterfaceIndex 排序取到 `192.168.206.1`（VMware/Hyper-V），手机不在该网段。改为取持有默认路由的网卡 → 实测 `192.168.0.105（以太网）`。
5. **cpolar 未认证**：日志只一行 `not found authtoken.` 就退出。现在脚本能识别并给出 `cpolar authtoken <token>` 指引 + 免注册的 cloudflared 备选。
6. **公网打不开（根因）**：穿透的是 **Vite dev server**，浏览器发几百个模块请求，每个都在隧道里往返 → 新增 `-Preview` 用打包产物。

## 四、已知取舍 / 明天演示前请注意

- **默认会暴露公网**：账号 `admin / 12345678`。日常开发用 `-NoTunnel`，演示完 `.\stop-dev.ps1`（会一并关隧道）。
- **cpolar 免费版带宽约 1~2 Mbps**，主 chunk 2.6 MB，公网首屏可能十几秒。**局域网秒开、公网慢就是带宽瓶颈**，此时优先用局域网演示，或换 Tailscale（点对点不限速）。
- **AI 问答首次约 20s**（本机向量化），走公网更久 → 演示前先问一个问题预热。
- **手机上 <760px 会隐藏两处**：右上角登录态 `.user-login-status`、AI 助手右侧引用来源 `.doc-panel`（演示 RAG 时想看到引用就用横屏/平板）。
- `-Preview` 模式下改代码要重跑脚本（无热更新）。
- Ollama 必须在本机运行：`ollama serve`，模型 `qwen3-embedding:4b`。
